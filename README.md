关键词：
- 极简
- 留白
- 几何
- 秩序
- 数字化
- 独立品牌
- 轻科技感
视觉上参考现代 SaaS 产品、独立软件公司和设计工作室，而不是传统发卡平台。

视觉风格 极简岛屿 · Minimal Island
核心理念： 将「屿」抽象成一个独立的数字空间。
- 白色、暖灰色作为主背景。
- 黑色作为品牌主色。
- 雾蓝色作为辅助强调色。
- 使用抽象几何图形、空间切面、悬浮模块。
- 大量留白，排版简洁。
这种风格有品牌辨识度，而且不会让网站看起来像套模板的商城。
