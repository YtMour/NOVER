# 2026-11-19 v0.3.0 版本审计：可运营闭环

## 1. 审计范围

在 v0.2.0（HEAD `97b2d6a`）基础上完成「可运营闭环」大版本，覆盖：

- 商品资料 v2：亮点、授权、技术要求、支持期、商品级更新策略与独立公开详情接口；
- 交付策略：更新策略在兑换码签发时快照、兑换时复制到权益，交付与票据按策略过滤版本；
- 退款售后：手工退款、权益收回与审计留痕；
- 成员管理：创建成员、角色/状态调整、暂停即撤销会话；
- 账户安全：修改密码（保留当前会话）、会话列表、撤销单个/其他设备；
- 租户审计日志：API 与控制台视图（筛选 + 分页 + 元数据展开）；
- 配套迁移、权限点、单元测试、跨平台冒烟、文档与 UI。

审计使用本地 Compose 实例与合成数据；未提交、未推送、未部署公网。

## 3. 主要改动

### 3.1 数据库

- `0003_product_profile_and_accounts.sql`：`products` 新增 `highlights/license_terms/requirements/support_period/update_policy/update_until`；`redeem_codes`、`entitlements` 新增策略快照列；新增策略 CHECK 约束与审计查询索引；演示商品补充合成资料。
- 历史权益策略为 NULL 时按 `LIFETIME` 处理，升级无需手工迁移。

### 3.2 后端

- 商品资料校验与公开详情：`GET /products/{id}`、`GET /spaces/{slug}/products/{id}`。
- 更新策略快照与交付过滤（`entitlementAssetVisibilitySQL`），交付/票据共用同一可见性条件。
- 退款 `REFUND`（兑换码 `REFUNDED` + 权益 `REVOKED` + 审计原因）。
- 成员创建/更新（`member.manage`）、暂停撤销会话、不能修改自己或 OWNER。
- 密码修改（`token_version` 递增、保留当前会话、撤销其他设备）、会话列表/撤销。
- 审计日志查询（`audit.read`，`limit/offset`、action/resource_type 过滤）。
- 登录限流 30 次/分钟/IP；CORS 允许 `PATCH`；会话 `last_seen_at` 最多 5 分钟更新一次。

### 3.3 前端

- 用户端：商品详情改用独立详情接口，新增亮点 chips 与“商品资料”语义区块（授权/支持期/技术要求/更新策略）；交付页展示更新范围并修正 `CURRENT_ONLY` 文案。
- 控制台：商品编辑新增资料与更新策略区块；兑换记录支持退款；成员视图支持创建/改角色/暂停；新增“账户与安全”（改密、会话）与“审计日志”（筛选、分页、元数据）视图；hash 深链扩展 `#account`/`#audit`。

### 3.4 DX / AX

- 新增第三套跨平台冒烟并纳入 `run-all.ps1`；修复 Windows PowerShell 5.1 下 JSON 中文乱码（UTF-8 字节 + charset）。
- API/架构/产品定义/路线图/README/AGENTS/CHANGELOG 同步；新增迁移不改旧迁移的原则继续生效。

## 4. 剩余风险与边界

1. **身份安全仍不完整**：无 MFA/Passkey、邀请邮件、密码重置；成员初始密码需线下告知。
2. **租户隔离**：仍无 PostgreSQL RLS，跨租户负向矩阵需覆盖新接口（成员、审计、会话、公开详情）并持续自动化。
3. **退款联动**：仅手工退款；外部平台订单/退款自动同步、售后票据未实现。
4. **审计与保留**：审计日志只读展示，无导出/归档/保留策略；`admin_events` 持续增长。
5. **浏览器验证不足**：控制台新视图尚未做真实浏览器交互与可访问性验收；建议引入 Playwright/axe。
6. **CI 未实跑**：GitHub Actions 需首跑确认 pwsh + Compose 冒烟。
7. **其他生产化缺口**：S3/扫描、备份恢复、指标告警、Redis 共享限流、多实例验证。
