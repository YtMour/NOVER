# 迭代路线

## 阶段 0：规则和边界

目标：让后续实现不会把开源代码和售卖资产混在一起。

- [x] 确定 NOVER 品牌和视觉基线
- [x] 确定开源平台代码与售卖文件分离
- [x] 确定 React/TypeScript/Tailwind/Go/Docker Compose 方向
- [ ] 固化兑换、下载、更新、退款规则
- [ ] 确认开源许可证和第三方依赖许可策略
- [x] 加入 `.env`、运行卷和常见交付归档的 Git 忽略规则

目标：启动一个可测试的空平台。

- [x] 初始化前端和 Go API 工程
- [x] 加入 PostgreSQL schema 初始化
- [x] 加入 Docker Compose 开发环境
- [x] 实现健康检查、配置加载和结构化日志
- [x] 建立统一错误码、请求 ID；审计目前只记录下载事件
