## 3. 本轮主要改动

### 3.1 后端与数据

- 迁移目录 `server/internal/db/migrations/`：`0001_baseline.sql`（原 schema.sql）、`0002_maintenance_indexes.sql`；迁移器支持版本排序、重复检测、校验和校验、单事务应用、历史安装自动基线。
- `cmd/maintenance` + `internal/maintenance`：数据库过期数据标记/删除与私有文件孤儿清理，默认干跑；单元测试覆盖扫描、路径逃逸与删除。
- 访问日志中间件、`X-Request-Id`、`/api/v1/meta`、`internal/buildinfo` 与 Docker 构建参数。
- 限流器返回剩余窗口，所有限流点输出 `Retry-After`。
- 交付接口返回下载额度；活动接口分页；申请审核幂等冲突返回 409。
- `Dockerfile` 同时构建 API 与维护命令；Compose 增加 API 健康检查与 `ops` profile。

### 3.2 前端

- 双端 skip-link、焦点样式、ARIA 状态与主题按钮语义；控制台 hash 深链与标题同步；目录搜索；交付额度/有效期/行级 pending/复制反馈；429 与网络错误提示。
- 未引入新依赖；双端均通过 `tsc -b && vite build`。

### 3.3 DX / AX

- `scripts/qa/curl-upload.ps1` 跨平台上传辅助；两套冒烟脚本兼容 PS 5.1/7/Linux 并新增额度断言。
- `scripts/qa/run-all.ps1`、`scripts/verify.ps1`、`scripts/verify.sh`。
- `.github/workflows/ci.yml`、PR 模板、`.gitattributes`、`.editorconfig`。
- `AGENTS.md`（160 行）、`docs/development.md`、`docs/operations.md`、`docs/api.md`。

## 4. 剩余风险与边界

1. **生产多租户仍不完整**：无 PostgreSQL RLS，跨租户负向矩阵尚未覆盖图片/权益/票据/活动全部入口；开放公网多租户前必须补齐。
2. **身份安全**：邀请设密、MFA、密码重置、全设备会话未实现；当前仅 bcrypt + 可撤销会话。
3. **存储与内容安全**：仍为本地私有卷，无 S3 适配、病毒扫描、归档检查；孤儿清理依赖人工执行 cron。
4. **可观测性**：有结构化日志与请求 ID，但无指标、追踪、告警；限流为进程内单实例。
5. **备份恢复**：文档给出流程但未自动化，也未做恢复演练。
6. **前端验证**：本审计无浏览器自动化环境，UI 交互通过构建、产物字符串与代码审查验证；建议后续引入 Playwright/axe。
7. **CI 未实跑**：工作流需在 GitHub 首次运行验证（尤其 ubuntu 上 pwsh + Compose 冒烟）。
8. **文档与实现可能漂移**：新增迁移/API 后需同步 `docs/api.md`、README 与 AGENTS 的不变量。

## 5. 建议下一步（按优先级）

1. **发布闸门**：在 GitHub 上跑通 CI；补并发兑换、过期/撤销、备份恢复自动化测试。
2. **可真实售卖**：商品结构化字段（亮点/授权/技术要求/支持期/更新策略）、独立公开详情接口、退款状态联动。
3. **身份与隔离**：邀请一次性设密、MFA、密码重置、全设备会话、成员管理、RLS、跨租户负向矩阵。
4. **生产化**：S3 兼容存储与签名 URL、上传扫描队列、TLS/独立域名、发布回滚、备份恢复演练、指标/告警、Redis（多实例时）。
5. **体验**：买家自助查询/售后、目录搜索与筛选、多语言、ReactBits 组件、真机与跨浏览器可访问性验收。
