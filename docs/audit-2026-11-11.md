## 本轮修复与改进

1. 凭证 HMAC/令牌哈希在服务端定位租户，买家请求无需提交租户 ID；租户暂停后兑换、交付、下载票据与下载入口不再继续服务。
2. 商户公开入口 `/spaces/{tenant_slug}` 展示租户商品，并使用租户作用域读取效果图；商品详情 Markdown 图片链接同步转换为空间图片路由。
3. 已发布版本重复提交保持原 `published_at`；签发凭证和上传文件在事务中重新检查版本状态，减小与发布/撤回的竞争窗口。
4. 控制台新增交付文件清单、大小与哈希摘要、草稿文件删除；发布版本文件保持只读，删除动作写入审计记录。
5. 商品编辑中屏布局改为上下排列，避免预览仅剩极窄列；文件区域的字号、行距、悬浮反馈也作了调整。

## 尚存边界 / 下一阶段

- 尚无 PostgreSQL RLS、完整并发压力/故障注入测试、租户级备份恢复及多实例共享限流；当前结果不等于生产级 SaaS 验收。
- 文件删除采用数据库事务先提交、随后删除私有卷对象；若文件系统删除失败，会记录错误但需后续孤儿对象清理任务。
- 上传尚无病毒扫描、归档包检查与文件类型策略；公开上线前应增加扫描队列和隔离状态。
- 商户目录仍共享 NOVER 品牌与页面文案；自定义域名、品牌配置和商户独立主题属于后续阶段。
- 窄屏浏览器视口和关键页面已检查，但还需真机/跨浏览器可访问性验收、完整键盘流程及颜色对比度检查。
- 运行中的 `.env` 仍为本地开发配置；公网部署需更换凭证、启用 TLS、备份与监控。手动提交和推送由仓库维护者执行。
