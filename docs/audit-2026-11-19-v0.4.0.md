## 1. 审计范围

在 v0.3.0 基础上完成「可信身份 · 体验打磨」大版本：

- 运营账号 TOTP 两步验证（设置/启用/两步登录/恢复码/关闭）；

- 迁移 `0004`、单元测试、第四套跨平台冒烟、文档与审计。

本轮仅使用本地合成数据；未提交、未推送、未执行真实备份恢复或公网部署。

## 3. 主要改动

### 3.1 身份与安全

- `internal/totp`：RFC 6238（SHA-1 / 6 位 / 30 秒，±1 窗口），含 RFC 向量测试。
- MFA 流程：`setup` 返回 secret/otpauth/10 恢复码；`enable` 用验证码启用；登录两步（5 分钟 challenge）；`login/mfa` 接受 TOTP 或恢复码；`disable` 需密码 + 验证码/恢复码。secret 用 AES-GCM（密钥由 `OPERATOR_TOKEN_KEY` 派生）加密；恢复码只存 SHA-256 哈希且一次性。
- 邀请与重置：`operator_invitations` 表（INVITE / PASSWORD_RESET），token 只存哈希、一次性、72h/2h 有效；公开 `POST /api/v1/invitations/accept` 设密；接受重置会递增 `token_version` 并撤销全部会话；过期/撤销后同用户名可重新邀请（复用待激活占位账号）。
- 新增审计事件：`MFA_ENABLED`、`MFA_DISABLED`、`MFA_RECOVERY_USED`、`MEMBER_INVITED`、`INVITATION_ACCEPTED`、`PASSWORD_RESET_LINK_CREATED`、`PASSWORD_RESET_COMPLETED`。

### 3.2 运维与 DX/AX

- `/metrics`（`internal/metrics`）：按 chi 路由聚合的请求计数、in-flight、uptime、build_info。
- `scripts/ops/backup.ps1` / `restore.ps1` / README：pg_dump + 私有卷归档 + manifest 校验和；恢复必须 `-Confirm`，默认 `-DryRun`；PS 5.1/pwsh 7 兼容。
- `docs/design-system.md`：颜色/字体/间距/组件/动效/可访问性/页面验收清单，对齐 v0.4 实际类名与 token。
- AGENTS/README/API/架构/产品定义/路线图/开发/运维文档同步；新增第四套冒烟并纳入 `run-all.ps1` 与 CI。

### 3.3 用户体验与视觉

- 用户端：光箱（Portal、焦点陷阱、Esc/方向键/遮罩、滚动锁定、reduced-motion）、目录/详情/交付骨架屏、Toast（复用去重/暂停）、空状态插画、按钮/卡片/移动端打磨。
- 控制台：两步登录与 MFA 卡（secret/otpauth/恢复码复制与下载）、邀请成员/待处理邀请/重置密码链接、公开 `accept` 设密页、全局 Toast、列表骨架屏、移动端触控导航。
- 可访问性：`role=dialog`/`aria-modal`、`aria-live`、焦点回归、`--focus-ring`、44px 触控目标、深浅色对比度核对。

## 4. 剩余风险与边界

1. **MFA 恢复策略**：丢失验证器 + 恢复码后，当前版本没有后台强制重置入口，需要数据库级运维介入；建议下一版增加 OWNER 重置他人 MFA 或恢复码再生成（需二次确认与审计）。
2. **邀请交付**：系统不发送邮件，链接由运营者线下传递；撤销邀请会保留“待激活”占位成员，同用户名可重新邀请但成员列表暂无“取消邀请”入口，建议补清理动作。
3. **备份恢复**：脚本仅验证 dry-run/校验路径；真实 pg_dump/pg_restore、卷恢复未演练，上线前必须在隔离环境演练。
4. **浏览器验证**：用户端有 headless Chrome 实测；控制台新视图尚未做真实浏览器/键盘/移动端全流程回归。
5. **CI 未实跑**：四套冒烟使 CI smoke 时间变长，需在 GitHub 首跑确认超时与资源。
6. **既有生产化缺口**：RLS、跨租户负向矩阵全覆盖、S3/上传扫描、告警/追踪、多实例共享限流、外部退款同步。
7. **会话累积**：本地会话表持续增长（维护命令可清理），生产应配置 cron。

## 5. 建议下一步

1. 控制台浏览器/可访问性验收与 Playwright/axe 自动化；CI 首跑。
2. MFA 运维闭环：OWNER 重置成员 MFA/恢复码再生成、强制 MFA 策略、Passkey 评估。
3. 邀请体验：撤销后取消占位成员、邀请备注/过期提醒；邮件通道作为可选适配。
4. 备份恢复演练（隔离环境）+ 定时备份 + 恢复验收清单固化。
5. 生产化：RLS、跨租户负向矩阵、S3 + 扫描、告警/追踪、多实例限流。
6. 视觉与体验：控制台命令面板/更细的表格密度、用户端 chunk 拆分与性能预算。
